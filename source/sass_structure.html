Cách Tổ Chức Thư Mục & File SASS (7-1 Pattern)

Thư mục source/sass/ của dự án đã được khởi tạo tự động theo đúng mô hình chuẩn 7-1 Pattern.

📁 Cấu trúc thư mục đã tạo:

📂 source/sass/
├── 📄 main.scss         # File chính (Import tất cả các file con)
├── 📂 abstracts/        # _variables.scss, _mixins.scss, _functions.scss
├── 📂 base/             # _reset.scss, _typography.scss, _global.scss
├── 📂 layout/           # _header.scss, _footer.scss, _grid.scss
├── 📂 components/       # _buttons.scss, _cards.scss
├── 📂 pages/            # _home.scss
├── 📂 themes/           # _dark.scss
└── 📂 vendors/          # _bootstrap.scss

💡 Lợi ích chính:

  • Dễ bảo trì: Mỗi quy tắc CSS nằm ở một vị trí rõ ràng, dễ tìm kiếm.
  • Tái sử dụng cao: Quản lý biến và mixin tập trung tại abstracts/.
  • Tối ưu biên dịch: Chỉ biên dịch 1 file main.scss duy nhất ra CSS.
