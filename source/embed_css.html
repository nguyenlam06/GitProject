Bài Tập: Các Cách Nhúng CSS Vào Trang HTML

Phần 1: Inline Style (Nhúng trực tiếp trong thuộc tính style)

Tiêu đề sử dụng Inline CSS (Màu xanh dương)

Đoạn văn này được định dạng bằng Inline CSS với thuộc tính style trực tiếp trong thẻ html.

Phần 2: Internal Style (Viết trong thẻ <style> ở <head>)

Tiêu đề sử dụng Internal CSS (Màu đỏ)

Đoạn văn này được định dạng màu sắc bằng Internal CSS khai báo ở phần head.

Phần 3: External Style (Nhúng từ file CSS bên ngoài)

Tiêu đề sử dụng External CSS (Màu tím)

Đoạn văn này sử dụng lớp class khai báo trong tệp embed_css.css riêng biệt.
