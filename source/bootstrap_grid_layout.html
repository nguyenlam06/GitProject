Bài Viết Nổi Bật: Khám Phá Bootstrap 5 Grid System

Đăng ngày: 2026 | Tác giả: Admin

Hệ thống Lưới (Grid System) của Bootstrap sử dụng một chuỗi các containers, rows và columns để sắp xếp và căn chỉnh nội dung theo dạng chia cột linh hoạt.

Grid System được xây dựng dựa trên nguyên lý Flexbox và hoàn toàn đáp ứng (responsive). Nó được chia thành 12 cột trên mỗi hàng, cho phép bạn thiết lập tỉ lệ khung hình chính xác trên nhiều kích thước màn hình như Extra Small (xs), Small (sm), Medium (md), Large (lg), Extra Large (xl) và XXL.

Ưu Điểm Của Việc Sử Dụng Layout Responsive

Với sự phát triển của các thiết bị di động, trang web cần phải thích ứng tốt trên cả máy tính bàn, máy tính bảng lẫn điện thoại thông minh. Bootstrap Grid giúp chuyển đổi bố cục từ 2 cột trên Desktop sang 1 cột xếp chồng trên Mobile một cách mượt mà thông qua các class như col-12 col-lg-8.
