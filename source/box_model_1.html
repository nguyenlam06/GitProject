Giải thích công thức tính tổng chiều rộng (Total Width):

Theo mặc định trong CSS (box-sizing: content-box), tổng chiều rộng của phần tử div được tính như sau:

Total Width = width + padding (left + right) + border (left + right) + margin (left + right)

= 200px + (35px + 35px) + (20px + 20px) + (25px + 25px)
= 200px + 70px + 40px + 50px
= 360px
